What is Microsoft Excel?

Microsoft Excel is a powerful spreadsheet application from Microsoft for organizing, analyzing and visualizing data. It is part of the Microsoft Office suite and is one of the most widely used tools for data processing in business, education, finance and personal productivity.

Excel uses a grid of cells arranged in rows (numbered 1, 2, 3...) and columns (lettered A, B, C...) where you enter data, perform calculations, build charts and create analytical models.

Why Excel is used for data processing

📈 Data OrganizationStore large amounts of data in an organized, tabular format that is easy to read and manipulate.
🔢 CalculationsFormulas and functions calculate automatically, from basic arithmetic to advanced statistics.
📊 Data VisualizationProfessional charts, graphs and dashboards reveal trends and patterns.
🔍 Analysis ToolsPivot Tables, Power Query and advanced functions summarize data quickly.
🤝 CollaborationShare workbooks, track changes and co-author in real time with cloud features.
⚡ AutomationMacros, formulas and VBA remove repetitive work and reduce errors.

01Sheets and Workbooks

What is a Workbook?

A workbook is an Excel file holding one or more worksheets, saved as .xlsx (or .xls in older versions). Think of it as a binder with many pages.

A workbook with three sheets

The file Sales_Report_2024.xlsx is the workbook; “January Sales”, “February Sales” and “Summary” are its worksheets (tabs at the bottom).

What is a Worksheet?

A worksheet is a single page inside a workbook: a grid of cells where you enter and manipulate data.

🔢 Default structure1,048,576 rows and 16,384 columns (A to XFD)
📑 Multiple sheetsUnlimited (limited by memory)

08Logical Functions

Make decisions in formulas based on conditions.

IF + AND: who qualifies for a bonus?

Rule: a sale qualifies when Total > 2000 and Status = Paid.

fx=IF(AND(C2>2000, D2="Paid"), "Qualified", "Not Qualified")

Formula in E2, filled down. Notice West Laptop (5,600) fails because it is still Pending.

FunctionWhat it doesExample → Result
IF()One value if TRUE, another if FALSE=IF(4000>2000,"High","Low") → High
Nested IF()Tests several conditions in order=IF(A1>=90,"A",IF(A1>=80,"B",IF(A1>=70,"C","F"))) with A1 = 85 → B
IFS() (365)Cleaner than nested IF=IFS(A1>=90,"A",A1>=80,"B",A1>=70,"C",TRUE,"F") with A1 = 85 → B
AND()TRUE only if ALL are true=AND(4000>2000, "Paid"="Paid") → TRUE
OR()TRUE if ANY is true=OR(A1="Red",A1="Blue") with A1 = Blue → TRUE
NOT()Reverses TRUE/FALSE=NOT("Paid"="Cancelled") → TRUE
XOR()TRUE if an odd number of conditions are TRUE=XOR(60>50, 40>50) → TRUE
IFERROR()Handles any error gracefully=IFERROR(10/0,"Error") → Error
IFNA()Handles only #N/A (common in lookups)=IFNA(VLOOKUP("Tablet",B2:C5,2,0),"Not Found") → Not Found
SWITCH()Match a value against several cases=SWITCH("M","S","Small","M","Medium","L","Large","Unknown") → Medium

Combining logical functions

=IF(AND(A1>100, B1="Active"), "Qualified", "Not Qualified")
=IF(OR(A1="Premium", B1>5000), "VIP", "Regular")
=IFERROR(IF(A1/B1>0.5, "High", "Low"), "No Data")
Use IFS() instead of nested IF() when you have 3+ conditions; it is far easier to read and maintain.

10Lookup Functions

Find and retrieve data from tables. All examples use this small price list:

Find the price of a Monitor four ways

fx=VLOOKUP("Monitor", B2:C5, 2, FALSE)
fx=XLOOKUP("Monitor", B2:B5, C2:C5)
fx=INDEX(C2:C5, MATCH("Monitor", B2:B5, 0))

All return 220. MATCH finds Monitor at position 3; INDEX returns the 3rd value in C2:C5.

Looking LEFT: get the product code

fx=XLOOKUP("Monitor", B2:B5, A2:A5)
fx=INDEX(A2:A5, MATCH("Monitor", B2:B5, 0))

Both return P03. VLOOKUP cannot do this because the code column is to the left of the lookup column.

fx=XLOOKUP("Tablet", B2:B5, C2:C5, "Not Found")

Returns Not Found instead of #N/A.

INDEX-MATCH for a 2D lookup: West sales in Feb

MATCH("West") → row 2 of the body, MATCH("Feb") → column 2, so INDEX returns 5,600.

Four rule types applied to the same Total column

Managing rules

  1. Select cells → Home → Conditional Formatting.

  3. Set conditions and formatting.
  4. “Manage Rules” edits, deletes or reorders; “Clear Rules” removes formatting.
Rule priority: when several rules apply, the first rule in the list wins. Reorder in Manage Rules; tick “Stop If True” to block lower rules.

14Data Consolidation

Combines data from several ranges, worksheets or workbooks into one summary, e.g. monthly sales from different regions.

Consolidate Units by product from 3 regional sheets (function: Sum)

→

Laptop 5 + 7 + 3 = 15 · Mouse 20 + 40 + 15 = 75 · Monitor 6 + 4 + 12 = 22

Steps

  1. Create a “Summary” sheet.
  2. Data → Consolidate; function: Sum.
  3. Add references: East!A1:B4, West!A1:B4, South!A1:B4.
  4. Tick “Top row” and “Left column” (to match by labels).
  5. Tick “Create links to source data” for dynamic updates.
  6. OK.

Methods

MethodHow it worksBest for
By positionCombines the same cell positions across sheetsIdentical layouts
By categoryMatches row/column labelsDifferent layouts but the same category names
Create linksBuilds an outline with expandable source detail; updates automaticallyDynamic summaries

Functions available: Sum (most common), Count, Average, Max/Min, Product, StdDev/Var.

Alternatives

📊 Pivot TablesMore flexible for complex analysis and multiple summaries.
🔗 Power QueryBest for large data, different structures and regular refreshes.
📝 Formulas=SUM(East!B2, West!B2, South!B2) or a 3D reference:
=SUM(East:South!B2)
3D reference shortcut: =SUM(Sheet1:Sheet5!B2) adds B2 from every sheet between Sheet1 and Sheet5 (including them).

16Power Query Editor

Power Query connects to data sources, cleans and transforms data, and loads it into Excel, with no complex formulas. Every change is recorded as a step you can replay with one click when the source updates.

Open it: Data tab → Get Data. Sources include files (Excel, CSV, Text, XML, JSON, PDF), databases (SQL Server, Access, Oracle), Azure, online services (SharePoint, Web), the current table/range, and other sources (OData, Web API, Blank Query).

Building a dashboard: step by step

  1. Define purpose & audience: what decisions will it support, who uses it, what questions must it answer?
  2. Gather & prepare data: collect → clean with Power Query → structure in Tables → build Pivot Tables/calculations.
  3. Design layout: sketch on paper, plan a grid, most important info top-left.
  4. Create the data structure: a Data sheet (raw, can be hidden), a Calculations sheet (formulas, pivots) and a Dashboard sheet (visuals only).
  5. Build visualizations: create and format charts; remove clutter (gridlines, extra labels).
  6. Add interactivity: Slicers, Timelines, Form Controls.
  7. Apply professional formatting: consistent colors, clear labels, white space, alignment; hide worksheet gridlines.
  8. Test & refine: test every control, get feedback, simplify.
